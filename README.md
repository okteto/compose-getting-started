# Develop a Docker Compose application with Okteto

This example shows how to use the [Okteto CLI](https://github.com/okteto/okteto) to deploy a Docker Compose application to Kubernetes, run its unit tests, and develop it with hot reload. The application is a FastAPI voting app that stores its votes in Redis.

This is the application used for the [Develop a Docker Compose application with Okteto](https://www.okteto.com/tutorials/compose-getting-started/) tutorial.
